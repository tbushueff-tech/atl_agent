# Atl Agent — самостоятельный демонстрационный генератор

Статический сайт для проверки **сериализации свойств, zlib Deflate, двойной подписи DSA (SHA-1)** и упаковки бинарного результата в Base64-контейнер.

**Важно:** используется новая, специально созданная для этого проекта и опубликованная тестовая DSA-пара. Результат имеет демонстрационный смысл и не является настоящей лицензией Atlassian или иной коммерческой системы. Не используйте ключи в целях безопасности или продакшен-лицензирования.

## Содержимое

- `index.html` — автономный интерфейс сайта;
- `src/generator.js` — сериализация контейнера, две подписи DSA и Base64;
- `src/properties.js` — подготовка свойств, поле `Description = License for <organization>`, даты и порядок HashMap;
- `src/private-key.js` — опубликованный **демонстрационный** PKCS#8 DSA-ключ;
- `test/generator.test.mjs` — проверка упаковки, сериализации и подписи.

В проекте нет Jira Helper, Cloudflare Worker, авторизации или хранилища сообщений.

## Запуск

В репозитории выполните:

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

Для проверки:

```sh
npm test
```

Нужен Node.js 22+.

## GitHub Pages

Настройте в **Settings → Pages → Build and deployment → Deploy from a branch**, выберите `main`, папку `/(root)` и нажмите **Save**. Адрес будет `https://tbushueff-tech.github.io/atl_agent/`.

Оригинальный репозиторий `tbushueff-tech/vibejira` не затрагивается.
